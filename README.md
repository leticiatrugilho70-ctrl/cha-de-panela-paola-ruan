# Lista de Presentes — Paola & Ruan (V3)

Versão de teste com painel administrativo completo.

## Rodar no Windows
1. Abra o terminal nesta pasta.
2. `pip install -r requirements.txt`
3. `python app.py`
4. Site: http://127.0.0.1:5000
5. Painel: http://127.0.0.1:5000/admin

O painel V3 mostra um selo “V3”. Se ele não aparecer, uma versão antiga ainda está aberta/rodando.
